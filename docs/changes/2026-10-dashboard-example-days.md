# Dashboard example days

These 27 check-ins are made-up examples so you can see every dashboard chart filled in. They are not real data.

**Where they appear:** only in the demo account (demo@withme.app / withme123). That's the browser build, or a phone build made with `--dart-define=WITHME_DEMO=true`. A normal phone install never adds them.

**Dates:** each one is a number of days before the day the app is opened. Today is always left empty so you can do a check-in live. The dates below assume the app is opened on Thu, Oct 8, 2026.

**Which period shows which days:**
- 7 days: #1 to #6
- 30 days: #1 to #18
- 90 days: #1 to #25
- All: all 27

## What the examples are set up to show
- **Written answers that match:** they count as one answer when they match after ignoring capitals and extra spaces.
  - "Commute" (#3, #16) and " commute " (#6) become one Work slice, Commute.
  - "Jaw clenching" is written twice under Body (#6, #20).
- **A typed answer that matches a built-in one counts as the built-in:**
  - "boss" typed under Work (#13) counts as Boss.
  - "mental" typed as a strategy (#15) counts as Mental.
- **Custom actions under built-in strategies:** "Planning my week" under Mental (#9) and "Baking" under Creative (#14).
- **Only the five offered strategies:** every example uses Mental, Physical, Emotional, Creative or Social. (Until 2026-10-12, five days used made-up custom strategies, "Nature" and "Rest"; they were switched to Physical so no "Action: Nature" or "Action: Rest" card appears.)
- **One written answer on every page that has a written "Other"**, so each detail pie shows a written slice somewhere.
